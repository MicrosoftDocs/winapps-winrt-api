# Microsoft.Windows.Media.Capture.CameraCaptureUIMode

<!--
public enum CameraCaptureUIMode
-->


## -description

Specifies the capture mode of an instnace of [CameraCaptureUI](cameracaptureui.md).

## -enum-fields

### -field PhotoOrVideo: 0

The UI allows the user to capture photos and videos.

### -field Photo: 1

The UI only allows the user to capture photos.

### -field Video: 2

The UI only allows the user to capture videos.

## -remarks

Specify the desired mode by passing a value from this enumeration into the call to [CameraCaptureUI.CaptureFileAsync](cameracaptureui_capturefileasync_269443891.md).
