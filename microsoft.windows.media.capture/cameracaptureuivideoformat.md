# Microsoft.Windows.Media.Capture.CameraCaptureUIVideoFormat

<!--
public enum CameraCaptureUIVideoFormat
-->


## -description

Specifies the file format of videos captured with an instance of [CameraCaptureUI](cameracaptureui.md).

## -enum-fields

### -field Mp4: 0

MP4/H.264/AAC format.

### -field Wmv: 1

WMV format.

## -remarks

Specify the desired format for an instance of **CameraCaptureUI** with the [CameraCaptureUIVideoCaptureSettings.Format](cameracaptureuivideocapturesettings_format.md) property.
