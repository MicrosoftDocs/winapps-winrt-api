# Microsoft.Windows.Media.Capture



## -description

Provides APIs for configuring an launching the [CameraCaptureUI](cameracaptureui.md) which allows the user to capture photos, videos, or both. 

## -remarks

Using **CameraCaptureUI** is an easy way to add basic photo and video capture functionality to a Windows app without having to create any custom camera UI and without having to use any low-level camera APIs. For more advanced scenarios that require custom camera UI or more refined control over the capture pipeline, use the [MediaCapture](/uwp/api/windows.media.capture.mediacapture) class. For more information, see [Camera](/windows/apps/develop/camera/camera).
