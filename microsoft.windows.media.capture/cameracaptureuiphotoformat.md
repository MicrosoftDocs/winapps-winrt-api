# Microsoft.Windows.Media.Capture.CameraCaptureUIPhotoFormat

<!--
public enum CameraCaptureUIPhotoFormat
-->


## -description

Specifies the file format of photos captured with an instance of [CameraCaptureUI](cameracaptureui.md).

## -enum-fields

### -field Jpeg: 0

JPEG format.

### -field Png: 1

PNG format.

### -field JpegXR: 2

JpegXR format.

## -remarks

Specify the desired format for an instance of **CameraCaptureUI** with the [CameraCaptureUIPhotoCaptureSettings.Format](cameracaptureuiphotocapturesettings_format.md) property.
