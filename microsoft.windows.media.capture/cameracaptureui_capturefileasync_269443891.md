# Microsoft.Windows.Media.Capture.CameraCaptureUI.CaptureFileAsync(Microsoft.Windows.Media.Capture.CameraCaptureUIMode)

## -description

Launches the camera capture UI, allowing the user to capture photos, videos, or both.

## -parameters

### -param mode

The capture mode, which specifies whether the UI allows photo capture, video capture, or both.

## -returns

An asynchronous operation that returns a [StorageFile](/uwp/api/windows.storage.storagefile) object upon completion. If the returned object is null, the user did not complete the photo or video capture.
