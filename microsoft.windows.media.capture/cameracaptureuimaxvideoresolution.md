# Microsoft.Windows.Media.Capture.CameraCaptureUIMaxVideoResolution

<!--

-->


## -description

Specifies the maximum resolution the user can select for capturing videos with [CameraCaptureUI](cameracaptureui.md).

## -enum-fields

### -field HighestAvailable: 0

The user can select any resolution.

### -field LowDefinition: 1

The user can select resolutions up to low definition resolutions.

### -field StandardDefinition: 2

The user can select resolutions up to standard definition resolutions.

### -field HighDefinition: 3

The user can select resolutions up to high definition resolutions.

## -remarks

Specify the desired maximum video resolution for an instance of **CameraCaptureUI** with the [CameraCaptureUIVideoCaptureSettings.MaxResolution](cameracaptureuivideocapturesettings_maxresolution.md) property.
