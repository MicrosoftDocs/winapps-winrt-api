# Microsoft.Windows.Media.Capture.CameraCaptureUI

<!--

-->


## -description

Provides a full window UI for capturing audio, video, and photos from the device's camera as well as controls for cropping photos, trimming video, time-delayed capture, and camera settings.

## -remarks

This API is available for Windows apps that use the Windows App SDK. UWP apps must use the legacy [CameraCaptureUI](/uwp/api/windows.media.capture.cameracaptureui?view=winrt-26100) class from the [Windows.Media.Capture](/uwp/api/windows.media.capture) namespace.

**CameraCaptureUI** provides an easy way to add basic photo and video capture functionality to a Windows app without having to create any custom camera UI and without having to use any low-level camera APIs. For more advanced scenarios that require custom camera UI or more refined control over the capture pipeline, use the [MediaCapture](/uwp/api/windows.media.capture.mediacapture) class. For more information, see [Camera](/windows/apps/develop/camera/camera).
