# Microsoft.Windows.Media.Capture.CameraCaptureUIVideoCaptureSettings.MaxResolution

## -description

Gets or sets a value from the [CameraCaptureUIMaxVideoResolution](cameracaptureuimaxvideoresolution.md) enumeration that specifies the maximum resolution the user will be able to select in the camera capture UI for video capture.

## -property-value

The maximum resolution for video capture.
