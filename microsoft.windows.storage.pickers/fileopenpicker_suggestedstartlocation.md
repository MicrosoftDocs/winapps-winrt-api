# Microsoft.Windows.Storage.Pickers.FileOpenPicker.SuggestedStartLocation

<!--

## -description

Specifies the initial location of the file picker when it is opened.

## -property-value

Gets or sets the initial location of the file picker. This is a value from the [PickerLocationId](pickerlocationid.md) enumeration.

## -remarks

If not specified, **PickerLocationId.Unspecified** is used by default.
