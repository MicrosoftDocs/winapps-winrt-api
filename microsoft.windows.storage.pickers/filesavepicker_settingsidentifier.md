# Microsoft.Windows.Storage.Pickers.FileSavePicker.SettingsIdentifier

<!--
public string SettingsIdentifier { get; set; }

## -description

Specifies the identifier for the settings of the file picker. This identifier is used to save and restore the state of the file picker.

## -property-value

Gets or sets the identifier for the settings of the file picker.
