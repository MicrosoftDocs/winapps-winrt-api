# Microsoft.Windows.Storage.Pickers.FileSavePicker.FileTypeChoices

<!--

## -description

The categorized extensions types. If not specified, allow All Files `*.*` is used. 

## -property-value

Gets the categorized extensions types for the file picker.

## -remarks

Note that when allow All Files is used, end users can save a file without a file extension.
