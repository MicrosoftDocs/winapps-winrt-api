# Microsoft.Windows.Storage.Pickers.FileOpenPicker.#ctor(Microsoft.UI.WindowId)

<!--

## -description

Creates a new instance of the **FileOpenPicker** class, with the specified [WindowId](/windows/windows-app-sdk/api/winrt/microsoft.ui.windowid) to reference the parent for the file picker dialog.

## -parameters

### -param windowId

The ID of the window that will be the parent of the file picker. This is used to set the window handle for the file picker.
