# Microsoft.Windows.Storage.Pickers.FileSavePicker.SuggestedFolder

<!--
public string SuggestedFolder { get; set; }
-->

## -description

The folder that is suggested for the user to save the file.

## -property-value

Gets or sets the suggested folder name for the file picker. The default value is the user's Documents library.

## -remarks

This property is only a suggestion and does not guarantee that the file will be saved in the specified folder.
