# Microsoft.Windows.Storage.Pickers.FolderPicker.SuggestedStartLocation

<!--

## -description

Specifies the initial location as a [PickerLocationId](pickerlocationid.md). If not specified, **PickerLocationId.Unspecified** is used as the default location.

## -property-value

Gets or sets the suggested start location for the folder picker.
