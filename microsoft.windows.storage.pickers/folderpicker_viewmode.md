# Microsoft.Windows.Storage.Pickers.FolderPicker.ViewMode

<!--

## -description

Specifies the [PickerViewMode](pickerviewmode.md) of the folder picker. The view mode determines how the items in the folder picker are displayed.

## -property-value

Gets or sets the view mode of the folder picker.
