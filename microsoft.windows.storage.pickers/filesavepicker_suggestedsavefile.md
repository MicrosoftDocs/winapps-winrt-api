# Microsoft.Windows.Storage.Pickers.FileSavePicker.SuggestedSaveFile

<!--

## -description

Specifies the default file to display when the picker is opened. If not specified, the system default value is used.

## -property-value

Gets or sets the default file for the file picker.

## -remarks

This property is used to suggest a file to the user when the file picker is opened. It can be set to a specific file that the user may want to save to, or it can be left unset to allow the user to choose any file.
