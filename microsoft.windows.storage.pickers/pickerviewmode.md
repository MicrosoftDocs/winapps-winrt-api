# Microsoft.Windows.Storage.Pickers.PickerViewMode

<!--
public enum PickerViewMode
-->

## -description

Indicates the view mode that the file picker is using to present items.

## -enum-fields

### -field List: 0

Displays items in a list view.

### -field Thumbnail: 1

Displays items as thumbnails.
