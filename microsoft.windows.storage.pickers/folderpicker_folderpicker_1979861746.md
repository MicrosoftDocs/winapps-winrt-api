# Microsoft.Windows.Storage.Pickers.FolderPicker.#ctor(Microsoft.UI.WindowId)

<!--

## -description

Creates a new instance of the **FolderPicker** class with a [WindowId](/windows/windows-app-sdk/api/winrt/microsoft.ui.windowid) to reference the parent for the folder picker dialog.

## -parameters

### -param windowId

The ID of the window that will be the parent of the folder picker. This is used to set the window handle for the folder picker.
