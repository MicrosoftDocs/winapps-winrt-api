# Microsoft.Windows.Vision.ScreenRegionBoundingBox

<!--
public struct ScreenRegionBoundingBox
-->

## -description

Represents a bounding box that defines a rectangular region of the display.

## -struct-fields

### -field Bottom

The y-axis value of the bottom of the rectangle.

### -field Left

The x-axis value of the left side of the rectangle.

### -field Right

The x-axis value of the right side of the rectangle.

### -field Top

The y-axis position of the top of the rectangle.
