# Microsoft.Windows.Vision.ScreenRegionLabel

<!--
public enum ScreenRegionLabel
-->

## -description

Specifies the labels used to describe the type of object within a [ScreenRegionBoundingBox](screenregionboundingbox.md).

## -enum-fields

### -field Text: 0

Text block.

### -field Image: 1

Raster or vector image.

### -field Table: 2

Tabular data.

### -field Container: 3

Container of text and images.

### -field Menu: 4

Menu bar or similar navigation controls.

### -field ToolBar: 5

A bar of tools or similar tool container (e.g., Windows Ribbon).

### -field AddressBar: 6

Text field for web site addresses or search terms.

### -field Toolpane: 7

Panel containing a collection of tools (e.g., Photoshop floating panes).

### -field TabBar: 8

A bar of tabs (Edge browser, Windows File Explorer).

### -field TitleBar: 9

Window title bar.
