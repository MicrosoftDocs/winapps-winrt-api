# Microsoft.Windows.AI.Text.ConversationSummaryOptions.Language

<!--
public string Language { get; set; }

## -description

Gets or sets the output language of the conversation summary.

## -property-value

The output language of the conversation summary.

## -remarks

Currently supports the following languages: English, German, French, Spanish, Italian, Portuguese, Chinese (Simplified), Japanese.
