## -description

Generates a response to an embedding vector prompt while returning progress for each token generated by the language model.

## -parameters

### -param context

The context window that defines the tokens a language model can process at one time for understanding an input prompt and then generating a response. The context window acts like the model's short-term memory, holding the input prompt and the preceding conversation to maintain coherence.

### -param promptEmbedding

The embedding vector prompt requiring a response.

### -param options

Options that affect how the language model responds to the prompt.

## -returns

The response to the prompt.

## -remarks

Generates a response from pre-computed embedding vectors with a [LanguageModelContext](languagemodelcontext.md) for multi-turn conversation history and [LanguageModelOptions](languagemodeloptions.md) for content moderation configuration.
