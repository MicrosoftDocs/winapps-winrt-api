# Microsoft.Windows.AI.Text.LanguageModelResponseStatus

<!--
public enum LanguageModelResponseStatus
-->

## -description

Specifies the possible states of the language model response.

## -enum-fields

### -field Complete: 0

Language model has returned the complete response.

### -field InProgress: 1

Languange model is still generating the response.

### -field BlockedByPolicy: 2

Generative AI is blocked by system or user permissions.

### -field PromptLargerThanContext: 3

Prompt is larger than the context window and cannot be used to generate a response. Trim prompt with [GetUseablePromptLength](languagemodel_getusablepromptlength_261255212.md) (or destroy and create a new context).

A context window acts like the model's short-term memory, holding the input prompt and the preceding conversation to maintain coherence. A larger context window enables more detailed conversations and processes larger documents but increases processing time, cost, and potentially reduces accuracy.

### -field PromptBlockedByContentModeration: 4

The input prompt was blocked by Text Content Moderation (TCM) or a Text Block List (TBL).

### -field ResponseBlockedByContentModeration: 5

Response generated by language model was blocked by Text Content Moderation (TCM) or a Text Block List (TBL).

### -field Error: 6

Response generated an error. Call [LanguageModelResponseResult.Status](languagemodelresponseresult_status.md) for extended error information.
