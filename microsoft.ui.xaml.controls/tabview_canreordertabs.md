# Microsoft.UI.Xaml.Controls.TabView.CanReorderTabs

<!--
public bool CanReorderTabs { get; set; }
-->

## -description

Gets or sets a value that indicates whether the tabs in the TabStrip can be reordered through user interaction.

## -property-value

`true` if the tabs in the TabStrip can be reordered through user interaction; otherwise, `false`. The default is `true`.

## -remarks

For more info, design guidance, and code examples, see [Tab view](/windows/apps/design/controls/tab-view).
