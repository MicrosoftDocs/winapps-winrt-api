# Microsoft.UI.Xaml.Controls.TextBox.Text

## -description

Gets or sets the text contents of the text box.

## -xaml-syntax

```xaml
<TextBox Text="string"/>
```

## -property-value

A string containing the text contents of the text box. The default is an empty string ("").

## -remarks

This property is not nullable. However, if you set this property to `null` (`TextBox1.Text = null;`) no exception is thrown. Instead, it is automatically set to an empty string ("").
