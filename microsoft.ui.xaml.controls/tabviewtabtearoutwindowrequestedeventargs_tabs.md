# Microsoft.UI.Xaml.Controls.TabViewTabTearOutWindowRequestedEventArgs.Tabs

<!--

## -description

Gets the selected tabs that are being dragged.

## -property-value

The selected tabs that are being dragged.

## -remarks

> [!NOTE]
> This API does not assume that only a single tab is selected. However, the [TabView](tabview.md) control does not currently provide a way to select multiple tabs.
