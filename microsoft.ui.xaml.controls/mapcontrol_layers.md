# Microsoft.UI.Xaml.Controls.MapControl.Layers

<!--
public System.Collections.Generic.IList<Microsoft.UI.Xaml.Controls.MapLayer> Layers { get; set; }
-->

## -description

Gets the collection of map layer objects that are children of the `MapControl`.

## -property-value

The collection of map layer objects that are children of the `MapControl`. The default is an empty collection.

## -remarks

Each layer contains [MapElement](mapelement.md) objects rendered on top of the map. The first layer in the collection is the bottom-most layer rendered in the map.
