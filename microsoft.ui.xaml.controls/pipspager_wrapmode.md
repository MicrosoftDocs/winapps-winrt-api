# Microsoft.UI.Xaml.Controls.PipsPager.WrapMode

<!--
public Microsoft.UI.Xaml.Controls.PipsPagerWrapMode WrapMode { get; set; }
-->

## -description

Gets or sets a value that determines whether the `PipsPager` control wraps between the first and last items.

## -property-value

A value of the enumeration that determines whether the `PipsPager` control wraps between the first and last items. The default is `None`.

## -remarks

Set this property to `Wrap` if you want the selected pip to wrap back to the first after the last one is reached, and vice-versa.
