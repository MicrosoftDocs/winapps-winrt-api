# Microsoft.UI.Xaml.Controls.NumberBox.ValidationMode

<!--
public Microsoft.UI.Xaml.Controls.NumberBoxValidationMode ValidationMode { get; set; }
-->

## -description

Gets or sets a value that specifies the input validation behavior to invoke when invalid input is entered.

## -property-value

A value of the enumeration that specifies the input validation behavior to invoke when invalid input is entered. The default is `InvalidInputOverwritten`.

## -remarks

For more information and examples, see [Number box - Enabling input validation](/windows/apps/design/controls/number-box#enabling-input-validation).
