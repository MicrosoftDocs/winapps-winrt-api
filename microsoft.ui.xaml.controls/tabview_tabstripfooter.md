# Microsoft.UI.Xaml.Controls.TabView.TabStripFooter

<!--

-->

## -description

Gets or sets the content that is shown to the right of the tab strip.

## -property-value

The element that is shown to the right of the tab strip, if there is one. The default is `null`.

## -remarks

The TabStripFooter property takes a single element. This is typically a layout panel, such as a `Grid` or `StackPanel`, that contains additional elements.
