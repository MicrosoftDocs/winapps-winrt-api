# Microsoft.UI.Xaml.Controls.SelectorBar

<!--

## -description

Represents a control that consists of a small group of options from which one is selected.

## -remarks

Use `SelectorBar` to let the user select between a small number of options to change the content shown. Only one option at a time can be selected. Some examples include:

- Switching between "Recent," "Shared," and "Favorites" views, where each view displays a unique list of content.
- Switching between "All," "Unread," "Flagged," and "Urgent" views, where each view displays a unique list of email items.
