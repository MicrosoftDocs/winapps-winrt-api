# Microsoft.UI.Xaml.Controls.PipsPagerWrapMode

<!--

## -description

Defines constants that specify how the [PipsPager](pipspager.md) control handles wrapping.

## -enum-fields

### -field None: 0

The PipsPager does not wrap after the first or last pip is reached.

### -field Wrap: 1

The PipsPager wraps back to the first pip after last pip is reached, and vice-versa.

## -remarks

This enumeration provides values for the [PipsPager.WrapMode](pipspager_wrapmode.md) property.
