# Microsoft.UI.Xaml.Controls.MapControl.ZoomLevel

<!--
public double ZoomLevel { get; set; }
-->

## -description

Gets or sets the zoom level of the map, which is a value between 0 and 24.

## -property-value

The zoom level of the map, which is a value between 0 and 24. The default is 0.

## -remarks

This is calculated using a Spherical Mercator projection coordinate system. See [Zoom levels and tile grid](/azure/azure-maps/zoom-levels-and-tile-grid) for more info.
