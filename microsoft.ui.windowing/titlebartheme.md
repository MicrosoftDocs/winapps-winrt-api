# Microsoft.UI.Windowing.TitleBarTheme

<!--
public enum TitleBarTheme
-->

## -description

Defines constants that specify what theme is used in the title bar.

## -enum-fields

### -field Legacy: 0

Legacy theming is used.

### -field UseDefaultAppMode: 1

The Windows default app mode theme is used.

### -field Light: 2

The light theme is used.

### -field Dark: 3

The dark theme is used.

## -remarks

This enumeration provides values for the [AppWindowTitleBar.PreferredTheme](appwindowtitlebar_preferredtheme.md) property.
