# Microsoft.UI.Windowing.AppWindow.Create(Microsoft.UI.Windowing.AppWindowPresenter,Microsoft.UI.WindowId,Microsoft.UI.Dispatching.DispatcherQueue)

<!--
public static Microsoft.UI.Windowing.AppWindow Create (Microsoft.UI.Windowing.AppWindowPresenter appWindowPresenter, Microsoft.UI.WindowId ownerWindowId, Microsoft.UI.Dispatching.DispatcherQueue DispatcherQueue);
-->


## -description

Creates a window with styles and properties as defined in the specified `AppWindowPresenter`, parented to the specified window, and associated with the specified `DispatcherQueue`.

## -parameters

### -param appWindowPresenter

An `AppWindowPresenter` object that specifies property values to apply to the window.

### -param ownerWindowId

The ID of the parent window for the new window.

### -param DispatcherQueue

The dispatcher queue to associate with the new window.

## -returns

A new app window with the specified configuration.
