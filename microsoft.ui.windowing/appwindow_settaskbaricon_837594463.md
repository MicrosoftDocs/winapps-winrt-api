# Microsoft.UI.Windowing.AppWindow.SetTaskbarIcon(Microsoft.UI.IconId)

<!--
public void SetTaskbarIcon (Microsoft.UI.IconId iconId);
-->

## -description

Sets the icon for the taskbar using the specified icon ID.

## -parameters

### -param iconId

The ID of the icon.

## -remarks

For more information about setting the icon, see [SetIcon](appwindow_seticon_931199135.md). This method works the same way, but lets you set the taskbar icon independently of the title bar icon.
