# Microsoft.UI.Windowing.AppWindow.SetTitleBarIcon(Microsoft.UI.IconId)

<!--
public void SetTitleBarIcon (Microsoft.UI.IconId iconId);
-->

## -description

Sets the icon for the window title bar using the specified icon ID.

## -parameters

### -param iconId

The ID of the icon.

## -remarks

For more information about setting the icon, see [SetIcon](appwindow_seticon_931199135.md). This method works the same way, but lets you set the title bar icon independently of the taskbar icon.
