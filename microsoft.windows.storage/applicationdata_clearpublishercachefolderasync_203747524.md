# Microsoft.Windows.Storage.ApplicationData.ClearPublisherCacheFolderAsync(System.String)

<!--
public Windows.Foundation.IAsyncAction ClearPublisherCacheFolderAsync (string folderName);
-->

## -description

Clears the files and subfolders from the specified subfolder of the shared storage folder for the publisher asynchronously.

## -parameters

### -param folderName

The name of the subfolder to clear.

## -returns

Returns an [IAsyncAction](/uwp/api/windows.foundation.iasyncaction) object that's used to track the asynchronous operation.
