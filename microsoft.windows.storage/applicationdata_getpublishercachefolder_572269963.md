# Microsoft.Windows.Storage.ApplicationData.GetPublisherCacheFolder(System.String)

<!--
public Windows.Storage.StorageFolder GetPublisherCacheFolder (string folderName);
-->

## -description

Gets the specified subfolder of the shared data store for the publisher of the app.

## -parameters

### -param folderName

The name of the subfolder to get.

## -returns

Returns a [StorageFolder](/uwp/api/windows.storage.storagefolder) object that represents the specified subfolder of the shared data store for the publisher of the app.
