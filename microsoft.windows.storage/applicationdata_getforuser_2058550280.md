# Microsoft.Windows.Storage.ApplicationData.GetForUser(Windows.System.User)

<!--
public static Microsoft.Windows.Storage.ApplicationData GetForUser (Windows.System.User user);
-->

## -description

Get an instance of [ApplicationData](applicationdata.md) for the specified user.

## -parameters

### -param user

The user for which to get the **ApplicationData** instance.

## -returns

## -remarks

Note that this is equivalent to [Windows.Storage.ApplicationData.GetForUserAsync()](/uwp/api/windows.storage.applicationdata.getforuserasync).
