# Microsoft.Windows.Storage.ApplicationData.SharedLocalPath

<!--
public string SharedLocalPath { get; }
-->

## -description

A string value that represents the path for the shared data store.

## -property-value

Returns the path for the shared data store.

## -remarks

This is equivalent to [Windows.Storage.ApplicationData.SharedLocalFolder().Path](/uwp/api/windows.storage.storagefolder.path).
