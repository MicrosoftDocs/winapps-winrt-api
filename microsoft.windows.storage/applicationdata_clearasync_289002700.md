# Microsoft.Windows.Storage.ApplicationData.ClearAsync(Microsoft.Windows.Storage.ApplicationDataLocality)

<!--
public Windows.Foundation.IAsyncAction ClearAsync (Microsoft.Windows.Storage.ApplicationDataLocality locality);
-->

## -description

Removes all data from the specified data store asynchronously.

## -parameters

### -param locality

The data store type to remove data from.

## -returns

Returns an [IAsyncAction](/uwp/api/windows.foundation.iasyncaction) object that's used to track the asynchronous operation.
