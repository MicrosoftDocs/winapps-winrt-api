# Microsoft.Windows.Storage.ApplicationData.LocalCacheFolder

<!--
public Windows.Storage.StorageFolder LocalCacheFolder { get; }

## -description

A [StorageFolder](/uwp/api/windows.storage.storagefolder) for the local cache data store, which is not included in backup and restore operations.

## -property-value

Returns a **StorageFolder** for the local cache data store.
