# Microsoft.Windows.Storage.ApplicationData.TemporaryPath

<!--
public string TemporaryPath { get; }
-->

## -description

A string value that represents the path for the temporary data store.

## -property-value

Returns the path for the temporary data store.

## -remarks

This is equivalent to [Windows.Storage.ApplicationData.TemporaryFolder().Path](/uwp/api/windows.storage.storagefolder.path).
