## -description

Creates a new [Task](task.md) for the internal implementation of [IBackgroundTask](/uwp/api/windows.applicationmodel.background.ibackgroundtask). It is used by Windows App SDK to receive the background task trigger and re-route the call to the full trust COM component registered by the application using the Windows App SDK API.
