# Microsoft.Windows.Widgets.Notifications.AnnouncementTextColor

<!--
public enum AnnouncementTextColor
-->


## -description

Specifies the color of text fields in a [FeedAnnouncement](feedannouncement.md).

## -enum-fields

### -field Default: 0

The default color.

### -field Dark: 1

The theme dark color.

### -field Light: 2

The theme light color.

### -field Accent: 3

The theme accent color.

### -field Good: 4

The theme color indicating a positive announcement.

### -field Warning: 5

The theme color indicating a warning announcement.

### -field Attention: 6

The theme color indicating an announcement that is requesting attention.
