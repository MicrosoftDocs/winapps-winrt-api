# Microsoft.Windows.Widgets.Notifications.FeedAnnouncement.IsSecondaryTextSubtle

<!--
public bool IsSecondaryTextSubtle { get; set; }
-->


## -description

Gets or sets a value indicating wether the [SecondaryText](/windows/windows-app-sdk/api/winrt/microsoft.windows.widgets.notifications/feedannouncement_secondarytext) string is displayed with subtle formatting to appear less prominent.

## -property-value

True if the secondary text should be displayed with subtle formatting; otherwise, false.

## -remarks

The default value is false.
