# Microsoft.Windows.Management.Deployment.PackageDeploymentProgressStatus

<!--
public enum PackageDeploymentProgressStatus
-->


## -description

Defines constants that specify the progress status of the deployment request.

## -enum-fields

### -field Queued: 0

The deployment request is queued.

### -field InProgress: 1

The deployment request is in progress.

### -field CompletedSuccess: 2

The deployment request completed successfully.

### -field CompletedFailure: 3

The deployment request failed with some critical internal error.
