# Microsoft.Windows.Management.Deployment.PackageSet.PackageUri

<!--
public System.Uri PackageUri { get; set; }
-->


## -description

Gets or sets an optional default URI for the package set; to be used if the [PackageSetItem.PackageUri](./packagesetitem_packageuri.md) of a package in the set isn't specified, and one is needed.

## -property-value

An optional default URI for the package set.
