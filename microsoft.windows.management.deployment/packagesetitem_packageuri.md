# Microsoft.Windows.Management.Deployment.PackageSetItem.PackageUri

<!--
public System.Uri PackageUri { get; set; }
-->


## -description

Gets or sets an optional property representing the package's uri. Some verbs use this property (see **Remarks** in [PackageSetItem](./packagesetitem.md)).

## -property-value

An optional property representing the package's uri. If not set, and a package uri is needed, then [PackageSet.PackageUri](./packageset_packageuri.md) is used.
