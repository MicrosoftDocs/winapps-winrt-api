# Microsoft.Windows.Management.Deployment.PackageVolume.IsRepairNeeded

<!--
public bool IsRepairNeeded ();
-->


## -description

Determines whether or not a call to [PackageVolume.Repair](./packagevolume_repair_1485508683.md) is needed. **IsRepairNeeded** doesn't require admin privilege.

## -returns

`true` if the package volume is damaged and needs to be repaired; otherwise, `false`.
