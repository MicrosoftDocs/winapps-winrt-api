# Microsoft.Windows.Management.Deployment.PackageVolume.Name

<!--
public string Name { get; }
-->


## -description

Gets the name of the package volume. A volume's *name* is the volume's media ID; so you can think of "volume name" as "volume media ID". Also see [System.VolumeId](/windows/win32/properties/props-system-volumeid).

## -property-value

The name (the media ID) of the package volume.
