# Microsoft.Windows.Management.Deployment.StubPackageOption

<!--
public enum StubPackageOption
-->


## -description

Defines constants that specify the stub behavior for an app package that's being added or staged.

## -enum-fields

### -field Default: 0

Use the default behavior.

### -field InstallFull: 1

Install as a full app.

### -field InstallStub: 2

Install as stub app.

### -field UsePreference: 3

Use the current [PackageSubPreference](./packagesubpreference.md) for the package.
