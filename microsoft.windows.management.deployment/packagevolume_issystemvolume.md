# Microsoft.Windows.Management.Deployment.PackageVolume.IsSystemVolume

<!--
public bool IsSystemVolume { get; }
-->


## -description

Gets a value indicating whether or not the volume is an internal system volume mapped to the `%SYSTEMDRIVER%` environment variable.

## -property-value

`true` if the volume is an internal system volume mapped to the `%SYSTEMDRIVER%` environment variable; otherwise, `false`.
