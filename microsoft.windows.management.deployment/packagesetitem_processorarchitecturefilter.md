# Microsoft.Windows.Management.Deployment.PackageSetItem.ProcessorArchitectureFilter

<!--

## -description

Gets or sets an optional property representing the package's processor architecture filter. Some verbs use this property (see **Remarks** in [PackageSetItem](./packagesetitem.md)).

## -property-value

An optional property representing the package's processor architecture filter. If not set, the default value is `Microsoft.Windows.ApplicationModel.DynamicDependency.PackageDependencyProcessorArchitectures.None`.
