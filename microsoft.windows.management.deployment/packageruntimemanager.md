# Microsoft.Windows.Management.Deployment.PackageRuntimeManager

<!--
public sealed class PackageRuntimeManager
-->


## -description

The **PackageRuntimeManager** class provides Dynamic Dependency support for [PackageSet](./packageset.md) operations, especially when the caller might not know the exact package(s) involved&mdash;for instance, when targeting
packages via `ms-uup:`. **PackageRuntimeManager** determines the packages involved for a **PackageSet**, and dynamically adds them to the caller's package graph.
