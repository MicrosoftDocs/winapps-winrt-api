# Microsoft.Windows.Management.Deployment.PackageSetItem.MinVersion

<!--

## -description

Gets or sets an optional property representing the package's minimum version. Some verbs use this property (see **Remarks** in [PackageSetItem](./packagesetitem.md)).

## -property-value

An optional property representing the package's minimum version. If not set, the default value is `0.0.0.0`.
