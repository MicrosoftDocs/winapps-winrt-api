# Microsoft.Windows.Management.Deployment.PackageVolume.SupportsHardLinks

<!--

## -description

Gets a value that indicates whether or not the volume supports the creation of hard links in its file system.

## -property-value

`true` if the volume supports the creation of hard links in its file system; otherwise, `false`.
