# Microsoft.Windows.Widgets.Providers.WidgetContextChangedArgs

<!--

## -description

Provides data for the [Microsoft.Windows.Widgets.Providers.IWidgetProvider.OnWidgetContextChanged](/windows/windows-app-sdk/api/winrt/microsoft.windows.widgets.providers.iwidgetprovider.onwidgetcontextchanged(microsoft.windows.widgets.providers.widgetcontextchangedargs)) callback.

## -remarks

In the current release, this callback is raised when the selected size of the widget within the widget host changes.
