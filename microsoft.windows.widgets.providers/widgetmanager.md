# Microsoft.Windows.Widgets.Providers.WidgetManager

<!--

## -description

Provides methods for querying, updating, and deleting widgets. 

## -remarks

This class can only perform operations on existing widgets. 

Get an instance of this class by calling [GetDefault](/windows/windows-app-sdk/api/winrt/microsoft.windows.widgets.providers/widgetmanager_getdefault_846721868).
