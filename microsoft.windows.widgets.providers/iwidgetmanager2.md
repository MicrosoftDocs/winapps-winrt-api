# Microsoft.Windows.Widgets.Providers.IWidgetManager2

<!--

## -description

An interface that is implemented by the [WidgetManager](/windows/windows-app-sdk/api/winrt/microsoft.windows.widgets.providers.widgetmanager) class, extending the functionality introduced with the [IWidgetManager](iwidgetmanager.md) interface.

## -remarks

This interface is a part of the underlying implementation of the widget framework and is not intended to be used directly by app developers who are implementing widget providers.
