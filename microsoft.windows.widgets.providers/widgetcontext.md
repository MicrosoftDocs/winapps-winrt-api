# Microsoft.Windows.Widgets.Providers.WidgetContext

<!--

## -description

Provides information about the configuration of a widget within the widget host.

## -remarks

Get an instance of this class by implementing the [WidgetContext)](/windows/windows-app-sdk/api/winrt/microsoft.windows.widgets.providers/iwidgetprovider_createwidget_1336245033) and [WidgetContextChangedArgs)](/windows/windows-app-sdk/api/winrt/microsoft.windows.widgets.providers/iwidgetprovider_onwidgetcontextchanged_948358590) methods of the [IWidgetProvider](/windows/windows-app-sdk/api/winrt/microsoft.windows.widgets.providers/iwidgetprovider) interface.
