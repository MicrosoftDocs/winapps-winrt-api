# Microsoft.Windows.Widgets.Providers.WidgetMessageReceivedArgs

<!--

## -description

Provides data for the [IWidgetProviderMessage.OnMessageReceived](iwidgetprovidermessage_onmessagereceived_511610511.md) event which is raised when the widget's content posts a message using the [window.chrome.webview.postMessage](/microsoft-edge/webview2/reference/javascript/webview) JavaScript method.
