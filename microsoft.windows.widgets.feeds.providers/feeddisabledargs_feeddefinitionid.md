# Microsoft.Windows.Widgets.Feeds.Providers.FeedDisabledArgs.FeedDefinitionId

<!--

## -description

Gets the unique identifier for the disabled feed, as specified in the app manifest of the feed provider app.

## -property-value

A string containing the ID of the disabled feed.

## -remarks

For more information, see [Feed provider package manifest XML format](/windows/apps/develop/feeds/feed-provider-manifest).
