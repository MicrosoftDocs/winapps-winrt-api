# Microsoft.Windows.Widgets.Feeds.Providers.FeedAnalyticsInfoReportedArgs.FeedProviderDefinitionId

<!--

## -description

Gets the definition ID of the feed provider associated with the analytics info.

## -property-value

The definition ID of the feed provider associated with the analytics info.

## -remarks

The feed provider definition ID is the value specified in the *Id* attribute of the **FeedProvider** element in the provider's package manifest file. For more information see [Feed provider package manifest XML format](/windows/apps/develop/feeds/feed-provider-manifest).
