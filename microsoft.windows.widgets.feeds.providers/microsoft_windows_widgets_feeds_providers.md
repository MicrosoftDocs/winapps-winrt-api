# Microsoft.Windows.Widgets.Feeds.Providers



## -description

Provides APIs for implementing a feed provider for Windows feeds.

## -remarks

[IFeedProvider](ifeedprovider.md) is the interface that must be implemented by feed providers in order to receive callback notifications for feed lifecycle events. This interface must be implemented as an Out-of-process COM Server.

The [FeedManager](feedmanager.md) class provides methods managing feeds.
