# Microsoft.Windows.Widgets.Feeds.Providers.IFeedAnnouncementInvokedTarget

<!--
public interface IFeedAnnouncementInvokedTarget
-->


## -description

The interface implemented by a feed provider to receive notifications when an announcement from the provider is displayed or when a user interacts with it.

## -remarks

Feed providers can make a request for an announcement to be displayed by calling <xref:Microsoft.Windows.Widgets.Feeds.Providers.FeedManager.TryShowAnnouncement(System.String,System.String,Microsoft.Windows.Widgets.Notifications.FeedAnnouncement)>.
