# Microsoft.Windows.Widgets.Feeds.Providers.CustomQueryParametersUpdateOptions

<!--

## -description

Conveys the query parameters and related metadata for calls to <xref:Microsoft.Windows.Widgets.Feeds.Providers.FeedManager.SetCustomQueryParameters(Microsoft.Windows.Widgets.Feeds.Providers.CustomQueryParametersUpdateOptions)>. 

## -remarks

Query parameters are passed to the remote feed provider URI when the Widgets Board is requesting feed content. This enables scenarios like passing authentication tokens to the remote service.
