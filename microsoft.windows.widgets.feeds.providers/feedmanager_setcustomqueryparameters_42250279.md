## -description

Sets the query parameters that are passed to the remote feed provider URI when the Widgets Board is requesting feed content. This enables scenarios like passing authentication tokens to the remote service.

## -parameters

### -param options

A [CustomQueryParametersUpdateOptions](/windows/windows-app-sdk/api/winrt/microsoft.windows.widgets.feeds.providers.customqueryparametersupdateoptions) object that conveys the query parameters and related metadata.
