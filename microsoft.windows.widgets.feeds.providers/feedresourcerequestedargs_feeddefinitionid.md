# Microsoft.Windows.Widgets.Feeds.Providers.FeedResourceRequestedArgs.FeedDefinitionId

<!--

## -description

Gets the definition ID of the feed associated with the resource request.

## -property-value

The definition ID of the feed associated with the resource request.

## -remarks

The feed definition ID is the value specified in the *Id* attribute of the **Definition** element in the provider's package manifest file. For more information see [Feed provider package manifest XML format](/windows/apps/develop/feeds/feed-provider-manifest).
