## -description

Gets the unique identifier of the enabled feed provider, as specified in the app manifest of the feed provider app.

## -property-value

A string containing the ID of the enabled feed provider.

## -remarks

For more information, see [Feed provider package manifest XML format](/windows/apps/develop/feeds/feed-provider-manifest).
