# Microsoft.Windows.Search.AppContentIndex

## -description

## -remarks

[!INCLUDE [App Content Search limited access notice](includes/app-content-search-laf.md)]

App Content Search indexes app-supplied text and images and returns a fused result set for a query, matching on keywords and, on devices with a supported NPU, by semantic similarity. The API applies the capabilities available on the device automatically. The app retains its original content; queries return app-defined content IDs.
