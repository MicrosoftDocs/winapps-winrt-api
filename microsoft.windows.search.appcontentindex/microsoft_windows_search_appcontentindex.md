# Microsoft.Windows.Search.AppContentIndex

## -description

## -remarks

> [!IMPORTANT]
> The `Microsoft.Windows.Search.AppContentIndex` APIs are a [Limited Access Feature](https://aka.ms/laffeatures). An app must obtain a token for feature ID `com.microsoft.windows.ai.appcontentindexer` and receive `LimitedAccessFeatureStatus.Available` from `LimitedAccessFeatures.TryUnlockFeature` before calling these APIs.

App Content Search indexes app-supplied text and images and returns a fused result set for a query, matching on keywords and, on supported NPU-enabled devices, on meaning. The API applies the capabilities available on the device automatically. The app retains its original content; queries return app-defined content IDs.
