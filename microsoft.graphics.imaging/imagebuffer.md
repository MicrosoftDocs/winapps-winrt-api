# Microsoft.Graphics.Imaging.ImageBuffer

<!--

## -description

Represents an uncompressed bitmap used for efficient cross-process marshaling.

## -remarks

This object can be used with AI model APIs such as [TextRecognizer](../microsoft.windows.ai.imaging/textrecognizer.md) that require image data. Typical usage involves creating an `ImageBuffer` from an existing [SoftwareBitmap](/uwp/api/windows.graphics.imaging.softwarebitmap).
