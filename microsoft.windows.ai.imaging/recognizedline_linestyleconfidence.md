# Microsoft.Windows.AI.Imaging.RecognizedLine.LineStyleConfidence

<!--

## -description

Gets a value that estimates the accuracy of the line style detected by text recognition.

## -property-value

An estimate of the accuracy of the line style detected by text recognition. This value ranges from 0.0 to 1.0, inclusive.
