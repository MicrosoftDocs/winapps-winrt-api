# Microsoft.Windows.AI.Imaging.ImageDescriptionKind

<!--
public enum ImageDescriptionKind
-->

## -description

Specifies the types of descriptions that can be generated from an image.

## -enum-fields

### -field BriefDescription: 0

Generated description is as succinct as possible.

### -field DetailedDescription: 1

Generated description contains more detail than a `BriefDescription`.

### -field DiagramDescription: 2

Generated description is optimized for a diagram.

### -field AccessibleDescription: 3

Generated description is optimized for accessibility.
