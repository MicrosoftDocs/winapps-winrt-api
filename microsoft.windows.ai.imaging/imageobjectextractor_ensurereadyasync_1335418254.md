# Microsoft.Windows.AI.Imaging.ImageObjectExtractor.EnsureReadyAsync

<!--

## -description

Ensures that the [ImageObjectExtractor](imageobjectextractor.md) is ready for use by downloading and installing any required components.

## -returns

An asynchronous operation with progress object that returns an [AIFeatureReadyResult](../microsoft.windows.ai/aifeaturereadyresult.md) on completion.
