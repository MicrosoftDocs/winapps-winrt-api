# Microsoft.Windows.AppNotifications.Builder.AppNotificationAudioLooping

<!--
public enum AppNotificationAudioLooping
-->


## -description

Specifies the looping behavior for app notification audio.

## -enum-fields

### -field None: 0

Audio is not looped.

### -field Loop: 1

Audio is looped.

## -remarks

To specify the looping behavior of app notification audio, use [AppNotificationBuilder.SetAudioEvent](/windows/windows-app-sdk/api/winrt/microsoft.windows.appnotifications.builder.appnotificationbuilder.setaudioevent)) or [AppNotificationBuilder.SetAudioUri](/windows/windows-app-sdk/api/winrt/microsoft.windows.appnotifications.builder.appnotificationbuilder.setaudiouri)).
