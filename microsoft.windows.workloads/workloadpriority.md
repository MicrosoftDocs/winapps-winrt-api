# Microsoft.Windows.Workloads.WorkloadPriority

<!--
public enum WorkloadPriority
-->

## -description

This enum defines the priority levels for workloads.

## -enum-fields

### -field Undefined: 0

The workload priority is undefined.

### -field Background: 1

The workload is running in the background.

### -field Foreground: 9

The workload is running in the foreground.
