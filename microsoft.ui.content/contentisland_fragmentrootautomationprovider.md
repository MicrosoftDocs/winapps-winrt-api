# Microsoft.UI.Content.ContentIsland.FragmentRootAutomationProvider

<!--
public object FragmentRootAutomationProvider { get; }
-->

## -description

Gets the fragment root automation provider.

## -property-value

The fragment root automation provider.

## -remarks

If the [**AutomationOption**](contentisland_automationoption.md) property is set to `FragmentBased`, the value is used to implement [**IRawElementProviderFragment::get_FragmentRoot**](/windows/win32/api/uiautomationcore/nf-uiautomationcore-irawelementproviderfragment-get_fragmentroot) for the automation provider.
