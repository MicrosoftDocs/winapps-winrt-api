# Microsoft.UI.Content.ContentIslandStateChangedEventArgs.DidLocalToParentTransformMatrixChange

## -description

Gets whether the local to parent transform matrix for the [**ContentIsland**](/windows/windows-app-sdk/api/winrt/microsoft.ui.content.contentisland) changed.

## -property-value

True, if the local to parent transform matrix for the [**ContentIsland**](/windows/windows-app-sdk/api/winrt/microsoft.ui.content.contentisland) changed; otherwise, false.
