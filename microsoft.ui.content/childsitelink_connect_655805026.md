# Microsoft.UI.Content.ChildSiteLink.Connect(Microsoft.UI.Content.ContentIsland)

<!--
public void Connect (Microsoft.UI.Content.ContentIsland content);
-->

## -description

Connects the specified [**ContentIsland**](contentisland.md) with the owned [**ContentSite**](contentsite.md).

## -parameters

### -param content

The [**ContentIsland**](contentisland.md) to connect with the owned [**ContentSite**](contentsite.md).

## -remarks

A [**ContentIsland**](contentisland.md) can only be connected to one [**ContentSite**](contentsite.md) at a time.
