# Microsoft.UI.Content.ContentIsland.PreviousSiblingAutomationProvider

<!--
public object PreviousSiblingAutomationProvider { get; }
-->

## -description

Gets the previous sibling automation provider.

## -property-value

The previous sibling automation provider.

## -remarks

If the [AutomationOption](contentisland_automationoption.md) property is set to `FragmentBased`, the value is used to implement [IRawElementProviderFragment::Navigate](/windows/win32/api/uiautomationcore/nf-uiautomationcore-irawelementproviderfragment-navigate) for the automation provider.
