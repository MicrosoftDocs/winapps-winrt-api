# Microsoft.UI.Content.ChildSiteLink.ProcessesKeyboardInput

<!--

## -description

Gets or sets a value indicating whether to process keyboard input.

## -property-value

True, if this [ChildSiteLink](childsitelink.md) process keyboard input; otherwise, false. The default is true.
