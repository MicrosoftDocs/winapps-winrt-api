# Microsoft.UI.Content.DesktopSiteBridge.IsSupported

<!--
public static bool IsSupported ();
-->

## -description

Gets whether a [DesktopSiteBridge](/windows/windows-app-sdk/api/winrt/microsoft.ui.content.desktopsitebridge) is supported in the current environment.

## -returns

True, if a [DesktopSiteBridge](/windows/windows-app-sdk/api/winrt/microsoft.ui.content.desktopsitebridge) is supported in the current environment; otherwise, false. The default is true.

## -remarks

A [DesktopSiteBridge](/windows/windows-app-sdk/api/winrt/microsoft.ui.content.desktopsitebridge) is not supported if running in a UWP environment, for example.
