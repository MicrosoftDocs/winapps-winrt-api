# Microsoft.UI.Content.ChildSiteLink.ProcessesPointerInput

<!--
public bool ProcessesPointerInput { get; set; }
-->

## -description

Gets or sets a value indicating whether to process pointer input.

## -property-value

True, if this [ChildSiteLink](childsitelink.md) process pointer input; otherwise, false. The default is true.

## -remarks

If this property is set to false then pointer input over the connected [**ContentIsland**](contentisland.md) is delivered to the parent [**ContentIsland**](contentisland.md). See [IContentSiteInput](icontentsiteinput.md) for more details.
