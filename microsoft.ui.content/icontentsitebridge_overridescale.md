# Microsoft.UI.Content.IContentSiteBridge.OverrideScale

<!--

## -description

Gets or sets the scaling factor used by a [ContentSite](/windows/windows-app-sdk/api/winrt/microsoft.ui.content.contentsite).

## -property-value

The scaling factor used by a [ContentSite](/windows/windows-app-sdk/api/winrt/microsoft.ui.content.contentsite).

## -remarks

Setting this value overrides the [Microsoft.UI.Content.ContentIsland.RasterizationScale](/windows/windows-app-sdk/api/winrt/microsoft.ui.content.contentisland.rasterizationscale) value.
