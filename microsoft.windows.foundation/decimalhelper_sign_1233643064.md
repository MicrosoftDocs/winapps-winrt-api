# Microsoft.Windows.Foundation.DecimalHelper.Sign(Microsoft.Windows.Foundation.DecimalValue)

<!--
public static int Sign (Microsoft.Windows.Foundation.DecimalValue value);

## -description

Retrieves the sign of the [DecimalValue](./decimalvalue.md).

## -parameters

### -param value

The [DecimalValue](./decimalvalue.md) to query about.

## -returns

0 if *value* is zero, or a negative value if *value* is less than 0, or a positive value if *value* is greater than 0.
