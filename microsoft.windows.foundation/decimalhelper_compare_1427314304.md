## -description

Compares the specified [DecimalValue](./decimalvalue.md) values.

## -parameters

### -param left

The first [DecimalValue](./decimalvalue.md) to compare.

### -param right

The second [DecimalValue](./decimalvalue.md) to compare.

## -returns

0 if *left* and *right* are equal, or a negative value if *left* is less than *right*, or a positive value if *left* is greater than *right*.
