## -description

Retrieves a [DecimalValue](./decimalvalue.md) whose value is the sum of the two specified parameters.

## -parameters

### -param left

The first value to sum.

### -param right

The second value to sum.

## -returns

A [DecimalValue](./decimalvalue.md) whose value is (*left* + *right*).
