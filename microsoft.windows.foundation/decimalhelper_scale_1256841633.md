# Microsoft.Windows.Foundation.DecimalHelper.Scale(Microsoft.Windows.Foundation.DecimalValue)

<!--

## -description

Retrieves the scaling factor of the [DecimalValue](./decimalvalue.md) (the number of decimal digits).

## -parameters

### -param value

The [DecimalValue](./decimalvalue.md) to query about.

## -returns

The scaling factor of the [DecimalValue](./decimalvalue.md) (the number of decimal digits), ranging from 0 to [MaxScale](./decimalhelper_maxscale_7876832.md).
