# Microsoft.Windows.Foundation.DecimalHelper.TryFromStringInvariant(System.String,Microsoft.Windows.Foundation.DecimalValue@)

<!--
public static bool TryFromStringInvariant (string source, out Microsoft.Windows.Foundation.DecimalValue value);
-->


## -description

Parses the string using the invariant locale, returning `false` on failure.

## -parameters

### -param source

The string to parse.

### -param value

The result of parsing the string into a [DecimalValue](./decimalvalue.md).

## -returns

`true` if successful, otherwise `false`.
