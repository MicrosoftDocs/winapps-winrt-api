# Microsoft.UI.Input.InputFocusNavigationHost.ContainsFocus

<!--
public bool ContainsFocus { get; }
-->

## -description

Gets whether the [Content.ContentIsland](../microsoft.ui.content/contentisland.md) corresponding to the associated [ContentSiteBridge](../microsoft.ui.content/icontentsitebridge.md) has focus.

## -property-value

True, if the [Content.ContentIsland](../microsoft.ui.content/contentisland.md) has focus. Otherwise, false.
