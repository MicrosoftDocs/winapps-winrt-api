# Microsoft.UI.Input.FocusNavigationRequest.Create(Microsoft.UI.Input.FocusNavigationReason,Windows.Foundation.Rect)

<!--

## -description

Creates an instance of [FocusNavigationRequest](focusnavigationrequest.md) using the specified [FocusNavigationReason](focusnavigationreason.md) and hint [Rect](/uwp/api/windows.foundation.rect).

## -parameters

### -param reason

The reason for a focus navigation event.

### -param hintRect

The bounding rectangle used to identify the focus candidates most likely to receive navigation focus.

## -returns

A [FocusNavigationRequest](focusnavigationrequest.md) object.
