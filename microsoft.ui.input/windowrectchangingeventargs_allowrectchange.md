# Microsoft.UI.Input.WindowRectChangingEventArgs.AllowRectChange

<!--
public bool AllowRectChange { get; set; }
-->

## -description

Gets or sets whether the window rect is allowed to change.

## -property-value

A value indicating whether or not the window rect is allowed to change. The default is true.

Setting this property to false prevents the window rect change from happening.
