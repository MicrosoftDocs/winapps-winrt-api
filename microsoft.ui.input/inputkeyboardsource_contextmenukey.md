# Microsoft.UI.Input.InputKeyboardSource.ContextMenuKey

## -description

Occurs when the **Menu** virtual-key (or Shift + F10) is unhandled from a previous [KeyDown](/windows/windows-app-sdk/api/winrt/microsoft.ui.input.inputkeyboardsource.keydown) event.

## -remarks

This event is not raised for context menu events generated from other hardware devices, such as mouse or pen.
