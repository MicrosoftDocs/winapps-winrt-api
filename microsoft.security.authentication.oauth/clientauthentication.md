# Microsoft.Security.Authentication.OAuth.ClientAuthentication

<!--
public sealed class ClientAuthentication
-->

## -description

A class that provides methods to create a client authentication object for basic authorization of the client to the authorization server.

>[!NOTE]
> This class is used to authenticate the client application to the authorization server. It isn't used to authenticate the user to the client application. User authentication is handled by the [RequestAuthWithParamsAsync](oauth2manager_requestauthwithparamsasync_742938245.md) method of the [OAuth2Manager](oauth2manager.md) class.
