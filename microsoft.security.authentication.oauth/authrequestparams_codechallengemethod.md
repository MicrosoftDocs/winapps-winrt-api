# Microsoft.Security.Authentication.OAuth.AuthRequestParams.CodeChallengeMethod

<!--

-->

## -description

Specifies the optional `code_challenge_method` parameter of the authorization request described by the section 4.3 of [RFC 7636](https://www.rfc-editor.org/rfc/rfc7636#section-4.3).

## -property-value

A [CodeChallengeMethodKind](codechallengemethodkind.md) enumeration value that specifies the `code_challenge_method` parameter of the authorization request.
