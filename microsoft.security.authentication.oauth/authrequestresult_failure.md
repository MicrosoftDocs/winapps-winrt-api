# Microsoft.Security.Authentication.OAuth.AuthRequestResult.Failure

<!--

-->

## -description

The failure information from a failed authorization request.

## -property-value

An [AuthFailure](authfailure.md) that represents the failure from the authorization request.

## -remarks

The values is non-null if the server's response indicates failure, otherwise it's null.
