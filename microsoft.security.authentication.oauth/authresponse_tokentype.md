# Microsoft.Security.Authentication.OAuth.AuthResponse.TokenType

<!--
public string TokenType { get; }
-->

## -description

Derived from the `token_type` parameter of the authorization response. This is available when [ResponseType](authrequestparams_responsetype.md) in [AuthRequestParams](authrequestparams.md) is set as `token`.

## -property-value

A **string** that represents the token type from the authorization response.
