# Microsoft.Security.Authentication.OAuth.AuthRequestParams.Scope

<!--
public string Scope { get; set; }
-->

## -description

Specifies the optional `scope` parameter of the authorization request described by the section 3.3 of [RFC 6749](https://www.rfc-editor.org/rfc/rfc6749#section-3.3).

## -property-value

A **string** containing the `scope` parameter of the authorization request.
