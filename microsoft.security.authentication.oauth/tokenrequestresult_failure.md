# Microsoft.Security.Authentication.OAuth.TokenRequestResult.Failure

<!--
public Microsoft.Security.Authentication.OAuth.TokenFailure Failure { get; }

## -description

The failure information for the token request. The value is non-null if the request failed, otherwise null.

## -property-value

A [TokenFailure](tokenfailure.md) object that contains the information for a failed token request.
