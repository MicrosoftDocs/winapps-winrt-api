# Microsoft.Security.Authentication.OAuth.ClientAuthentication.Authorization

<!--

## -description

Specifies the `Authorization` header of the HTTP POST request when requesting a token.

## -property-value

A [HttpCredentialsHeaderValue](/uwp/api/windows.web.http.headers.httpcredentialsheadervalue) that contains the authorization header value.
