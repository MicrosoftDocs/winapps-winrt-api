# Microsoft.Security.Authentication.OAuth.AuthRequestParams.ClientId

<!--
public string ClientId { get; set; }
-->

## -description

Specifies the required `client_id` parameter of the authorization request described by the section 2.2 of [RFC 6749](https://www.rfc-editor.org/rfc/rfc6749.html#section-2.2).

## -property-value

A **string** containing the `client_id` parameter of the authorization request.
