# Microsoft.Security.Authentication.OAuth.AuthResponse.AccessToken

<!--
public string AccessToken { get; }
-->

## -description

Derived from the `access_token` parameter of the authorization response. This value is available when [ResponseType](authrequestparams_responsetype.md) in [AuthRequestParams](authrequestparams.md) is set as `token`.

## -property-value

A **string** that represents the access token from the authorization response.
