# Microsoft.Security.Authentication.OAuth.TokenRequestParams.CreateForAuthorizationCodeRequest(Microsoft.Security.Authentication.OAuth.AuthResponse)

## -description

A helper method to create for an authorization code grant request (`authorization_code` grant type) with required parameters extracted from the authorization response.

## -parameters

### -param authResponse

An [AuthResponse](authresponse.md) object that contains the authorization response information.

## -returns

Returns a [TokenRequestParams](tokenrequestparams.md) object that contains the token request parameters.
