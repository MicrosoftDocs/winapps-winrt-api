# Microsoft.Security.Authentication.OAuth.AuthResponse.ExpiresIn

<!--
public string ExpiresIn { get; }
-->

## -description

Derived from the `expires_in` parameter of the authorization response. It's the lifetime of access token in seconds. This is available when [ResponseType](authrequestparams_responsetype.md) in [AuthRequestParams](authrequestparams.md) is set as `token`.

## -property-value

A **string** that represents the remaining lifetime of access token in seconds.
