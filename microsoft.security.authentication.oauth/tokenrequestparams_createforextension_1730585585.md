# Microsoft.Security.Authentication.OAuth.TokenRequestParams.CreateForExtension(Windows.Foundation.Uri)

<!--
public static Microsoft.Security.Authentication.OAuth.TokenRequestParams CreateForExtension (System.Uri extensionUri);
-->

## -description

A helper method to create for an extension grant request, using the provided URI for the grant type.

## -parameters

### -param extensionUri

The **System.Uri** for the extension grant type.

## -returns

Returns a [TokenRequestParams](tokenrequestparams.md) object that contains the token request parameters.
