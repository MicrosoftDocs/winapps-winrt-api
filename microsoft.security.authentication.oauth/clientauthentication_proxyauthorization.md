# Microsoft.Security.Authentication.OAuth.ClientAuthentication.ProxyAuthorization

<!--

## -description

Specifies the `Proxy-Authorization` header of the HTTP POST request when requesting a token.

## -property-value

A [HttpCredentialsHeaderValue](/uwp/api/windows.web.http.headers.httpcredentialsheadervalue) that contains the proxy authorization header value.
