# Microsoft.Security.Authentication.OAuth.AuthRequestParams.CodeChallenge

<!--
public string CodeChallenge { get; set; }
-->

## -description

Used as the Proof Key for Code Exchange (PKCE) `code_challenge` described by the section 4.2 of [RFC 7636](https://www.rfc-editor.org/rfc/rfc7636#section-4.2).

## -property-value

A **string** containing the `code_challenge` parameter of the authorization request.
