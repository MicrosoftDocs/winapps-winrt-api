# Microsoft.Security.Authentication.OAuth.AuthRequestParams.RedirectUri

<!--
public System.Uri RedirectUri { get; set; }
-->

## -description

Specifies the optional `redirect_uri` parameter of the authorization request described by the section 3.1.2 of [RFC 6749](https://www.rfc-editor.org/rfc/rfc6749.html#section-3.1.2).

## -property-value

A **System.Uri** containing the `redirect_uri` parameter of the authorization request.
