# Microsoft.Security.Authentication.OAuth.AuthResponse.Scope

<!--
public string Scope { get; }
-->

## -description

Derived from the `scope` parameter of the authorization response. This is available when [ResponseType](authrequestparams_responsetype.md) in [AuthRequestParams](authrequestparams.md) is set as `token`.

## -property-value

A **string** that represents the scope of the access token.
