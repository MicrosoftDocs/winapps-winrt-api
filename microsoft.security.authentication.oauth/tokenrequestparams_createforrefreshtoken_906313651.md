# Microsoft.Security.Authentication.OAuth.TokenRequestParams.CreateForRefreshToken(System.String)

<!--
public static Microsoft.Security.Authentication.OAuth.TokenRequestParams CreateForRefreshToken (string refreshToken);
-->

## -description

A helper method to create for an access token refresh request (`refresh_token` grant type) with required parameters.

## -parameters

### -param refreshToken

A **string** containing the refresh token.

## -returns

Returns a [TokenRequestParams](tokenrequestparams.md) object that contains the token request parameters.
