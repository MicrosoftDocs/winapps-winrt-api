# Microsoft.Security.Authentication.OAuth.AuthRequestParams.State

<!--
public string State { get; set; }
-->

## -description

Specifies the recommended `state` parameter of the authorization request described in section 4.1.1 of [RFC 6749](https://www.rfc-editor.org/rfc/rfc6749#section-4.1.1).

## -property-value

A **string** containing the `state` parameter of the authorization request.
