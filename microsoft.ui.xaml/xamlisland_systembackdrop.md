# Microsoft.UI.Xaml.XamlIsland.SystemBackdrop

<!--

-->

## -description

Gets or sets the custom system backdrop used to render [materials](/windows/apps/design/signature-experiences/materials) like [Mica](/windows/apps/design/style/mica) and [Acrylic](/windows/apps/design/style/acrylic) for the **XamlIsland**.

## -property-value

The custom system backdrop used to render [materials](/windows/apps/design/signature-experiences/materials) like [Mica](/windows/apps/design/style/mica) and [Acrylic](/windows/apps/design/style/acrylic) for the **XamlIsland**.
