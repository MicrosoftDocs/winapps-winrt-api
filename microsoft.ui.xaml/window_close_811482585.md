# Microsoft.UI.Xaml.Window.Close

## -description

Closes (destroys) the application window.

## -remarks

This method destroys the window. To hide the window without destroying it, call the [Window.AppWindow.Hide](../microsoft.ui.windowing/appwindow_hide_1985563870.md) method.

The [Closed](window_closed.md) event occurs when a [Window](window.md) closes.
